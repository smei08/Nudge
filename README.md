# Nudge

A creative prompt generator for artists and makers — when you're staring at a blank page, Nudge rolls a random idea to get you started.

 **[Live Demo → nudgeandcreate.netlify.app](https://nudgeandcreate.netlify.app/)**

> *"sometimes you just need a nudge..."*

---

## What It Does

Hit **Roll & Create** and get a random creative prompt drawn from 10 art and design categories. No accounts, no friction — just an idea to get you moving.

### Prompt Categories

- Drawing & Sketching
- Painting
- Markers & Ink
- Collage & Mixed Media
- Graphic Design & Digital
- Printmaking & Stamps
- Branding & Identity
- Typography & Lettering
- 3D & Sculpture
- Photography & Composition

| Technology | Purpose |

## Getting Started

```bash
# Clone the repo
git clone https://github.com/smei08/Nudge.git
cd Nudge

# Open in browser
open index.html
```

Or use [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code.

---

## Key Concepts Demonstrated

- JSON as a structured data source
- Dynamic DOM rendering from data
- Randomization logic in vanilla JavaScript
- Clean single-page UI with CSS
- Separation of data (`ideas.json`) from logic (`app.js`)
